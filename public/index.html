使用指南

配置说明与帮助文档

🚀 快速开始

  1. 配置 SillyTavern

    确保酒馆允许外部连接（见下方详细说明）

  2. 配置 NapCat

    启动 NapCat 并开启反向 WebSocket 服务

  3. 填写本桥接配置

    在"配置管理"页面填入正确的地址和参数

  4. 启动服务

    点击仪表盘上的"启动服务"按钮

⚠️ SillyTavern 配置说明（必读）

要让本桥接程序能够连接 SillyTavern，您需要修改酒馆的 config.yaml 配置文件。 该文件位于 SillyTavern 根目录下。

1. 启用远程连接监听

# 允许监听来自其他设备/程序的连接
listen: true

2. 配置 IP 白名单

将本桥接程序的 IP 加入白名单。如果在本机运行，使用 127.0.0.1：

whitelist:
  - ::1
  - 127.0.0.1
⚠️ 安全提示： 如果您需要快速测试，可以暂时设置为 0.0.0.0/0 允许所有连接。 但请注意这存在安全风险，测试完成后请恢复为具体 IP。 
# 仅用于测试，存在安全风险！
whitelist:
  - 0.0.0.0/0

3. Basic Auth 认证（可选）

如果您在酒馆启用了 Basic Auth，需要在本桥接的配置中填入相同的用户名和密码：

# SillyTavern 的 config.yaml 中的设置
basicAuthMode: true
basicAuthUser:
  username: "YourUsername"
  password: "YourPassword"
💡 提示： 修改 config.yaml 后需要重启 SillyTavern 才能生效。

🐱 NapCat 配置说明

确保 NapCat 的反向 WebSocket 服务已启动，默认地址为 ws://127.0.0.1:3001。

NapCat 配置示例

{
  "ws_reverse": {
    "enable": true,
    "url": "ws://127.0.0.1:3001"
  }
}
